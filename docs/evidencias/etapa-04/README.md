## Teste de persistência

A persistência não é comprovada apenas pela imagem final. O teste realizado foi: fechar o navegador, encerrar o servidor local, iniciar novamente o `INICIAR_RIFFLY.bat` e verificar que os dados continuaram disponíveis. A captura `07-persistencia.png` registra o estado final desse procedimento.
